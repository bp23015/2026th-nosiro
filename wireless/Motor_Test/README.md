## 仮基板の配線内容
- ESP32 WROOM 32E
- モータードライバ TB6643KQ * 2
- スイッチ
- リポバッテリー Zeee 11.1V 850mAh

## 利用方法
1. 仮基板にリポとモーターを接続する
2. スイッチを入れてESPが光ったのを確認し、機体にしまう
3. 白い固定具で前後から挟み、固定する
4. スマホ/PCでWifiに接続する
   (SSID: ESP32_MotorTest, Pass: esp32wroom)
5. ブラウザで「192.168.4.1」に接続し、html下部の「Connection」が「Connected」になっていることを確認する
7. 回転方向とスピードを選択し、モーターをONにする

## 足の収納方法
1. ジョイントがストッパとがっちり固定されていたら、(手で)正転させて足を相対的に逆回転し、固定を解除する
2. 手でジョイントを回し、機体側のガイドとジョイントの溝を合わせる
3. 手でジョイントの位置を固定し、モータを逆転させる
