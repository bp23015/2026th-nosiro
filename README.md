## 2026/07/05
###　追加事項(林)
- マージ作業を行った
- 各フェーズ毎に記録するフォーマットが変わるため、3つのファイルに分けてログを保存する
- マージプログラムは全部で5つのファイルから構成されている。merge_v1.inoに各変数が宣言されているので、そこで変数を変える。
- void loopの中は以下の順番になっている
1. 着地判定(ここは審議)が出されるまで、Landing_Check(着地判定関数)を回し続ける。この関数は、bme.inoにある。

2. 機体が、目的地の5m以内に近づくまでRunning(走行プログラム関数)を回し続ける。この関数はGPS_BNO.inoにある

3. 機体が目的地に近づいた後、Lidarを起動させ、Lidarの値が100(mm)以下かつGPSの値が5m以下になるまでGoal_decision(ゴール判定関数)を回し続ける。この関数はLidar_GPS.inoにある。

4. 無限ループに入らせ、機体を停止させる。
